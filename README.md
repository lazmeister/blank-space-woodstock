# Blank Space Woodstock Website Redesign

Static redesign for Blank Space, a boutique event venue and rental space in downtown Woodstock, Ontario.

## Local Preview

```powershell
python -m http.server 5173 --directory site-redesign
```

Then open:

```text
http://127.0.0.1:5173/index.html
```

## GitHub Pages

This repo includes a GitHub Actions workflow that publishes the `site-redesign/` directory to GitHub Pages.

After the repo is pushed to GitHub, enable Pages with **Settings -> Pages -> Build and deployment -> Source: GitHub Actions**.
