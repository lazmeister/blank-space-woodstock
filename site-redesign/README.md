# Blank Space Redesign

Static redesign prototype for Blank Space Woodstock.

## Run Locally

```powershell
python -m http.server 5173 --directory site-redesign
```

Open:

```text
http://127.0.0.1:5173/index.html
```

## Pages

- `index.html`
- `space.html`
- `pricing.html`
- `events.html`
- `planning.html`
- `faq.html`
- `contact.html`
- `book.html`

The contact and booking forms use `mailto:` so they work in a static prototype without a backend.
